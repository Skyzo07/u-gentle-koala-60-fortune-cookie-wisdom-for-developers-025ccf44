One original fortune-cookie line for a software developer, written by `main.ts` to `/output/entry.txt`:

> A green pipeline is not proof the code is right; it is proof the tests agree with your mistakes.

96 characters — inside the 1–120 gate, no trailing newline. The line was picked from 18 fresh candidates scored against the brief's five criteria in order; the CrowLLM judge panel was unusable (free tier returned HTTP 429/500 on nearly every call — see `panel-results.json`), so the internal winner stands.

## Run

```sh
node main.ts   # writes /output/entry.txt
```

Deterministic, no network, no clock. Requires Node 22+.
